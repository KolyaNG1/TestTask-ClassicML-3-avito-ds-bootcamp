# Поведенческие признаки

Все признаки в этом документе рассчитываются отдельно для одной куки. В расчёт
попадают только разрешённые события внутри полуинтервала
`window_start_ts <= event_ts < window_end_ts`. Показ капчи исключается до сборки
признаков.

Многие колонки образуют однотипные семейства. В таблицах такие семейства записаны
через шаблон имени, чтобы не повторять одно и то же описание для каждой категории,
платформы или квантиля. Полный фактический список колонок сохраняется вместе с
каждым набором признаков.

## Минимальный набор

| Признак | Что показывает | Как считается |
|---|---|---|
| `n_events` | Общий объём активности | Количество событий внутри окна |
| `item_nunique` | Число просмотренных объектов | Количество уникальных непустых `item_id` |

## Основная активность

| Признак или семейство | Что показывает | Как считается |
|---|---|---|
| `n_unique_timestamps` | Разнообразие моментов активности | Число уникальных `event_ts` |
| `n_event_types` | Разнообразие действий | Число уникальных `event_name` |
| `active_span_hours` | Длительность наблюдаемой активности | Разность последнего и первого события в часах |
| `active_minutes`, `active_hours` | Покрытие времени | Число минут и часов, в которых было хотя бы одно событие |
| `events_per_active_minute` | Плотность активности | `n_events / active_minutes` |
| `events_per_span_hour` | Средняя скорость на всём промежутке | `n_events / active_span_hours` |
| `category_nunique` | Разнообразие категорий | Число уникальных `item_category` |
| `location_nunique` | Разнообразие регионов | Число уникальных `item_location` |
| `query_nunique` | Разнообразие запросов | Число уникальных `search_query` |
| `search_page_nunique` | Разнообразие страниц поиска | Число уникальных `search_page` |
| `seller_type_nunique` | Разнообразие продавцов | Число уникальных типов продавца |
| `max_search_page` | Глубина просмотра выдачи | Максимальное значение `search_page` |
| `platform_nunique` | Число используемых платформ | Число уникальных нормализованных платформ |
| `main_platform` | Основная платформа | Самая частая нормализованная платформа |
| `count_<event>` | Объём конкретного действия | Количество событий каждого разрешённого типа |
| `share_<event>` | Структура действий | Доля конкретного типа среди всех событий куки |
| `has_<event>` | Наличие действия | 1, если тип события встречался, иначе 0 |
| `count_platform_<platform>` | Объём по платформе | Количество событий на web, desktop, Android и iOS |
| `share_platform_<platform>` | Доля платформы | Количество событий платформы / все события |
| `cookie_age_hours` | Возраст куки к началу окна | Разность `window_start_ts` и `cookie_created_at` в часах |
| `log_cookie_age` | Сглаженный возраст куки | `log(1 + max(cookie_age_hours, 0))` |
| `cookie_younger_than_<N>h` | Признак новой куки | 1, если возраст меньше 6, 24, 72 или 168 часов |

## Интервалы и сессии

| Признак или семейство | Что показывает | Как считается |
|---|---|---|
| `seconds_to_first_event` | Задержка начала активности | Секунды от начала окна до первого события |
| `seconds_after_last_event` | Остаток окна | Секунды от последнего события до конца окна |
| `activity_share_of_day` | Доля суток с активностью | Промежуток между первым и последним событием / 86400 |
| `interval_<stat>` | Распределение пауз | Среднее, медиана, минимум, максимум, стандартное отклонение и квантили разностей соседних событий |
| `interval_unique` | Разнообразие пауз | Число уникальных интервалов |
| `interval_mode_share` | Повторяемость пауз | Доля самого частого интервала |
| `interval_iqr`, `interval_mad` | Устойчивый разброс | Межквартильный размах и медианное абсолютное отклонение |
| `interval_cv` | Относительный разброс | Стандартное отклонение / средний интервал |
| `interval_q90_to_median` | Тяжесть правого хвоста | 90-й процентиль / медиана |
| `interval_near_median_share` | Регулярность | Доля интервалов не дальше двух секунд от медианы |
| `interval_positive_min` | Минимальная ненулевая пауза | Минимальный интервал строго больше нуля |
| `interval_multiple_of_<N>_share` | Кратность пауз | Доля положительных интервалов, кратных 5, 10 или 60 секундам |
| `interval_share_le_<N>s` | Быстрые действия | Доля интервалов не больше 0, 1, 2, 5, 10, 30 или 60 секунд |
| `interval_share_gt_<N>m` | Длинные паузы | Доля интервалов больше 5, 10, 30 или 60 минут |
| `max_events_per_minute`, `max_events_per_5min`, `max_events_per_hour` | Пиковая нагрузка | Максимальное число событий в соответствующем временном бакете |
| `share_busiest_minute`, `share_busiest_hour` | Концентрация активности | Доля событий в самом насыщенном бакете |
| `seconds_to_<N>pct_events` | Скорость накопления событий | Время от первого события до 25%, 50%, 75% и 90% действий |
| `events_day_quarter_<N>` | Положение внутри окна | Количество событий в каждой четверти суток |
| `share_<part>_events` | Время суток | Доли ночных, утренних, дневных и вечерних событий |
| `hour_sin_mean`, `hour_cos_mean` | Циклическое время | Средние синус и косинус часа события |
| `session_<N>m_count` | Число сессий | Сессии разделяются паузами больше 15 или 30 минут |
| `session_<N>m_size_<stat>` | Размер сессий | Среднее, медиана и максимум числа событий |
| `session_<N>m_span_<stat>` | Длительность сессий | Средняя и максимальная длительность в минутах |
| `session_<N>m_largest_share` | Концентрация в главной сессии | Доля событий самой большой сессии |
| `session_<N>m_gap_<stat>` | Межсессионные паузы | Средняя и максимальная пауза между сессиями |

## Структура поведения

| Признак или семейство | Что показывает | Как считается |
|---|---|---|
| `<field>_unique` | Разнообразие сущности | Число уникальных объектов, категорий, регионов или запросов |
| `<field>_unique_share` | Скорость перебора сущностей | Число уникальных значений / число непустых событий |
| `<field>_repeat_share` | Повторяемость | `1 - unique_share` |
| `<field>_top_share`, `<field>_top3_share` | Концентрация | Доля самого частого и трёх самых частых значений |
| `<field>_entropy` | Равномерность распределения | Энтропия частот значений |
| `<field>_concentration` | Концентрация Херфиндаля | Сумма квадратов долей значений |
| `<field>_singletons` | Однократные значения | Число значений, встречавшихся ровно один раз |
| `<field>_max_count` | Максимальная частота | Число появлений самого частого значения |
| `<field>_same_next_share` | Повтор подряд | Доля соседних событий с одинаковым значением |
| `<field>_switch_count` | Число переключений | Число смен значения между соседними моментами |
| `<field>_longest_run` | Длина серии | Максимальное число одинаковых значений подряд |
| `<field>_return_count` | Возвраты | Число возвратов к ранее встречавшемуся значению после переключения |
| `items_in_multiple_sessions` | Возвраты между сессиями | Число объявлений, встречавшихся более чем в одной сессии |
| `seller_<type>_share` | Профиль продавцов | Доля событий частных и профессиональных продавцов |
| `seller_<type>_views`, `seller_<type>_contacts` | Действия по типу продавца | Число просмотров и контактов для каждого типа |
| `search_page_<stat>` | Глубина поиска | Среднее, медиана и 90-й процентиль страницы выдачи |
| `search_page_gt_<N>_share` | Глубокий поиск | Доля страниц выше 1, 3, 5, 10 и 20 |
| `search_next_page_count` | Последовательный просмотр | Число переходов на следующую страницу |
| `search_reset_page_count` | Сброс выдачи | Число возвратов с глубокой страницы на первую |
| `query_length_<stat>` | Длина запроса | Средняя и максимальная длина текста |
| `query_word_count_mean` | Число слов | Среднее число слов в запросе |
| `query_digit_*` | Использование чисел | Число, доля и наличие цифр в запросах |
| `<action>_per_<base>` | Воронка действий | Отношения просмотров, фото, контактов, избранного и сообщений к предыдущему действию |
| `transition_<event1>_to_<event2>` | Переходы между действиями | Число переходов между событиями с различными временными метками |

## Полный набор

| Признак или семейство | Что показывает | Как считается |
|---|---|---|
| `main_user_agent` | Основная строка клиента | Самый частый непустой User-Agent |
| `ua_family`, `ua_os` | Семейство и ОС клиента | Правила по подстрокам User-Agent |
| `main_category`, `main_location`, `main_query`, `main_seller_type` | Основной контекст | Мода соответствующего поля |
| `ua_nunique`, `ua_family_nunique` | Разнообразие клиентов | Число уникальных строк и семейств |
| `ua_main_share` | Постоянство клиента | Доля основной строки User-Agent |
| `ua_switch_count` | Смена клиента | Число смен User-Agent между соседними моментами |
| `ua_has_<marker>` | Программный клиент | Наличие известных маркеров автоматизированных библиотек |
| `ua_is_program` | Обобщённый программный клиент | 1 для известных программных семейств |
| `ua_is_mobile` | Мобильный клиент | 1 для Android и iOS |
| `ua_platform_mismatch` | Несогласованность клиента и платформы | Мобильная ОС с desktop или настольная ОС с mobile |
| `category_platform`, `category_seller` | Контекстные сочетания | Склейка основной категории с платформой или типом продавца |
| `pointer_*` | Использование курсора | Покрытие координат, разброс, траектория, скорость и повторяемость точек |
| `count_category_<value>`, `share_category_<value>` | Профиль категорий | Количество и доля событий по словарю раннего train |
| `count_location_<value>`, `share_location_<value>` | Профиль регионов | Количество и доля событий по словарю раннего train |
| `count_<platform>_<event>` | Профиль платформ и событий | Количество каждого действия на каждой платформе |
| `log_<feature>` | Сглаженный масштаб | `log(1 + feature)` для основных счётчиков |
| `<entity>_per_<entity>` | Относительное разнообразие | Отношения событий, объявлений, категорий, регионов и запросов |

## Расширенный набор кандидатов

| Признак или семейство | Что показывает | Как считается |
|---|---|---|
| `events_per_span_minute` | Общая скорость | Число событий / длительность активности в минутах |
| `unique_items_per_span_minute` | Скорость обхода объявлений | Уникальные объявления / длительность активности |
| `unique_queries_per_span_minute` | Скорость смены запросов | Уникальные запросы / длительность активности |
| `max_events_same_timestamp` | Одновременные действия | Максимальное число событий с одинаковым временем |
| `same_timestamp_event_share` | Доля одновременных действий | Доля событий, относящихся к повторяющимся временным меткам |
| `event_second_*`, `event_minute_*` | Регулярность времени | Нули, кратность пяти, число уникальных значений и энтропия секунд и минут |
| `positive_interval_*` | Структура ненулевых пауз | Уникальность, частота моды и энтропия положительных интервалов |
| `fast_run_le_<N>s` | Быстрые серии | Максимальная серия событий с паузой не больше заданного порога |
| `<event>_timing_*` | Ритм отдельного действия | Длительность, квантили пауз и коэффициент вариации для каждого типа события |
| `events_on_item_*`, `views_per_item_*` | Интенсивность по объектам | Среднее и максимум действий или просмотров на объявление |
| `single_event_item_share`, `revisited_item_share` | Повторы объектов | Доля одноразовых и повторно просмотренных объявлений |
| `query_page_pair_nunique` | Разнообразие выдачи | Число уникальных пар запроса и страницы |
| `query_page_repeat_share` | Повтор выдачи | Доля повторяющихся пар запроса и страницы |
| `same_query_consecutive_share` | Повтор запроса подряд | Доля соседних поисковых событий с одинаковым запросом |
| `count_query_<NNN>`, `share_query_<NNN>` | Профиль запросов | Количество и доля запросов из словаря раннего train |
| `count_ua_family_*`, `share_ua_family_*` | Профиль клиента | Количество и доля событий по семействам User-Agent |
| `count_ua_os_*`, `share_ua_os_*` | Профиль ОС | Количество и доля событий по операционным системам |
| `count_seller_<type>_<event>` | Продавец и действие | Количество действий каждого типа по виду продавца |
