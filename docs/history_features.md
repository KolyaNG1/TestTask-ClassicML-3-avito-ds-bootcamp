# Дополнительные и исторические признаки

Этот каталог описывает признаки, появившиеся после базовых экспериментов. Первая
часть рассчитывается только по событиям текущей куки. Вторая часть использует
разметку исключительно более ранних дней.

## Последовательности событий

События с одинаковой временной меткой объединяются в один неупорядоченный момент.
Это важно: внутри одной временной метки точный порядок действий неизвестен.

| Признак или семейство | Что показывает | Как считается |
|---|---|---|
| `sequence_moment_count` | Число моментов активности | Количество уникальных временных меток |
| `sequence_token_nunique` | Разнообразие сочетаний действий | Число уникальных наборов событий в одном моменте |
| `sequence_token_entropy` | Равномерность сочетаний | Энтропия наборов событий |
| `sequence_transition_nunique` | Разнообразие переходов | Число уникальных переходов между соседними моментами |
| `sequence_transition_entropy` | Равномерность переходов | Энтропия переходов |
| `sequence_transition_repeat_share` | Повторяемость сценария | Доля повторных переходов |
| `sequence_longest_same_moment_run` | Одинаковые моменты подряд | Максимальная серия одинаковых наборов событий |
| `sequence_multi_event_moment_share` | Одновременные действия | Доля моментов с несколькими типами событий |
| `sequence_transition_hash_000…127` | Профиль переходов | Нормированные количества переходов, распределённых стабильным хешем по 128 корзинам |
| `sequence_trigram_hash_000…127` | Длинные сценарии | Нормированные количества троек событий в 128 корзинах |
| `sequence_<event1>__<event2>` | Содержательный переход | Число заранее выбранных переходов: из выдачи в объявление, из объявления к продавцу, в избранное или контакт, из чата в сообщение |

Всего блок содержит 270 признаков.

## Хешированное представление строк

Перед хешированием текст приводится к нижнему регистру и разбивается на устойчивые
фрагменты. Хеш не обучается на test и не хранит исходные значения.

| Семейство | Что показывает | Как считается |
|---|---|---|
| `ua_text_length` | Объём клиентских строк | Суммарная длина уникальных User-Agent куки |
| `ua_text_digit_share` | Числа в User-Agent | Доля цифровых символов в объединённой строке |
| `ua_text_version_token_count` | Версии клиента | Число фрагментов вида `число.число` |
| `query_text_length` | Объём запросов | Суммарная длина поисковых запросов |
| `query_text_word_count` | Слова в запросах | Число токенов после разбиения по пробелам |
| `query_text_digit_share` | Числа в запросах | Доля цифровых символов |
| `ua_text_hash_000…095` | Детали клиентских строк | Нормированные частоты символьных фрагментов длиной 3–5 в 96 стабильных корзинах |
| `query_text_hash_000…095` | Структура запросов | Нормированные частоты символьных фрагментов длиной 3–4 в 96 стабильных корзинах |

Всего блок содержит 198 признаков.

## История сущностей

Для обучающей куки доступны только сущности из строго предыдущих дней. Метки других
кук того же дня не используются. Для проверочного периода доступны только метки
его обучающей части. При финальном предсказании test использует весь размеченный
train, который заканчивается до начала test.

Для сущности считается сглаженная доля положительного класса:

```text
(число прошлых ботов + alpha × средняя доля ботов train)
-------------------------------------------------------
             число прошлых кук + alpha
```

В экспериментах используется `alpha = 25`.

| Признак или семейство | Что показывает | Как считается |
|---|---|---|
| `<entity>_history_seen_share` | Покрытие прошлой историей | Доля сущностей текущей куки, встречавшихся в прошлом |
| `<entity>_history_rate_mean` | Средняя репутация | Среднее сглаженных исторических долей ботов |
| `<entity>_history_rate_max` | Наиболее подозрительная сущность | Максимальная историческая доля ботов |
| `<entity>_history_rate_q75` | Верхняя часть репутаций | 75-й процентиль исторических долей |
| `<entity>_history_rate_std` | Разброс репутаций | Стандартное отклонение исторических долей |
| `<entity>_history_rate_top3_mean` | Сильнейшие сигналы | Среднее трёх максимальных исторических долей |
| `<entity>_history_count_mean` | Средний объём истории | Среднее число прошлых кук по сущностям |
| `<entity>_history_count_max` | Максимальный объём истории | Максимальное число прошлых кук для одной сущности |

Вместо `<entity>` используются:

| Префикс | Сущность |
|---|---|
| `item` | Объявление, внутренний ключ `item_id` |
| `query` | Поисковый запрос |
| `user_agent` | Полная строка User-Agent |
| `category_location` | Пара категории и региона |
| `ua_category` | Пара User-Agent и категории |

Сырые значения сущностей и любые колонки, заканчивающиеся на `_id`, после
агрегации в модель не передаются.

## Проверенные сочетания

| Финальное название | Состав |
|---|---|
| `behavior_with_entity_history` | Локальные поведенческие признаки и история всех пяти сущностей |
| `behavior_with_non_item_history` | Тот же набор без истории объявлений |
| `behavior_with_item_history` | Локальные признаки и только история объявлений |
